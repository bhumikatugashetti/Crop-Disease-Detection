# Crop Disease Detection and Treatment Recommendation System

An AI-based Crop Disease Detection and Treatment Recommendation System using Python, TensorFlow, and Flask.

## Project Structure
- `dataset/`: Directory to store the dataset.
- `disease_info/`: Information about crop diseases and treatments.
- `model/`: Directory to store the trained model files.
- `static/`: Contains static assets like CSS, JavaScript, and user uploads.
- `templates/`: Contains HTML templates for the Flask application.
- `venv/`: Python virtual environment.

## Getting Started

1. Activate the virtual environment:
   - On Windows: `.\venv\Scripts\activate`
   - On macOS/Linux: `source venv/bin/activate`

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
